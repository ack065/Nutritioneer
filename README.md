# Nutritioneer
Проект по предметот Бази на податоци 2026з - ментор: проф. Вангел Ајановски
Апликацијата е наменета за лесно одржување на конзистентност со здравата исхрана, следење на макро и микро хранливи материи, креирање и споделување на рецепти на едноставен начин.
Повеќе информации -> https://develop.finki.ukim.mk/projects/nutritioneer/wiki/WikiStart
